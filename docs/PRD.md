# Wish Willow：已授权需求摘要

来源：本次用户明确需求。不是长期 PRD 的扩展推断。

最终愿景是许愿式软件创造：人表达愿望与重大决策，Agent 承担常规软件工程；必须复用原版 DSH 插件机制与已有设施，产品事实独立于执行 Session。

P0 已于 2026-10-10 正式验收关闭。用户现明确授权 P1-A/P1-B/P1-C；契约见 [P1 任务](<../tasks/P1.md>)。P1 目标为从真实 Wish Willow UI 提交自然语言愿望，持久化正式产品状态、真实 DSH Agent 规划与 Coding、任务看板、真实构建/测试/运行及两轮可持续修改的软件交付。完成 P1 开发后停止，等待独立验收，不自动进入 P2。

P0 手动产品标签不表示 Agent 正在执行；愿望文本只由用户表单输入，不将模型推断标记为用户确认。P0 不引入 Agent/Tool/任务执行逻辑。

P1 保留 P0 代码/数据与单写入 Host，复用官方公开 Agent/权限/工具/UI，不建设完整多 Agent 平台。需求区分用户确认与 Agent 推断；任务与版本必须绑定真实证据。P1-C 必须在同一产品完成至少一次实际需求演化，不能仅生成代码文本或冒称未访问的预览可用。

P2 独立 Reviewer/复杂质量治理和 P3 接管/多模型调度不在当前范围。后续均需阶段验收与明确新授权。
